This component is a Third-Party Modified Version of the Fraunhofer FDK AAC Codec
Library for Android.

Modified on 2026-11-03.

AAC intensity stereo decisions, spectral conversion, short-block grouping,
and fixed-point square roots are adapted from the Android 7.1.1 release of
the FDK AAC library. The source uses the observed SDK namespace, energy unions,
noise-substitution layout, arithmetic, and scratch initialization. Existing
inverse-square-root and normalized-division implementations are reused.
Platform alternatives are omitted.
