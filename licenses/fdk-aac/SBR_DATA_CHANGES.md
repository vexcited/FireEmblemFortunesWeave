This component is a Third-Party Modified Version of the Fraunhofer FDK AAC Codec
Library for Android.

Modified on 2026-11-03.

SBR envelope reconstruction, noise decoding, concealment, and channel unmapping
are adapted from the Android 7.1.1 release of the FDK AAC library. The source
uses the observed SDK namespace, frame layout, fixed-point arithmetic, and
existing frequency helpers. Platform alternatives are omitted.
