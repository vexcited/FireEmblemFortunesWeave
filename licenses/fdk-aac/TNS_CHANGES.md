This component is a Third-Party Modified Version of the Fraunhofer FDK AAC Codec Library for Android.

Modified on 2026-11-03.

Temporal noise shaping synchronization and spectrum filtering are adapted from the Android 7.1.1 release of the FDK AAC library. The source uses the observed SDK namespace and structure layouts. Filtering uses 16-bit predictor coefficients. Zero-order filters are skipped. Zero-valued predictors preserve the observed normalization behavior. Platform alternatives are omitted.
