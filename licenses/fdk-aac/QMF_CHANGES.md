This component is a Third-Party Modified Version of the Fraunhofer FDK AAC Codec
Library for Android.

Modified on 2026-11-03.

The QMF analysis, synthesis, initialization, scaling, gain control, and
coefficient tables are adapted from the Android 7.1.1 release of the FDK AAC
library. The source uses the observed SDK namespace, 80-byte filter-bank layout,
16-bit analysis history and coefficients, and 32-bit synthesis history. Fixed-
point operations preserve the target integer widths. An unused local transform
exponent is initialized. Platform alternatives are omitted.
