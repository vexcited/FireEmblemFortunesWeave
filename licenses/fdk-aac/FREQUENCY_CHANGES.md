Third-Party Modified Version of the Fraunhofer FDK AAC Codec Library for Android.

Modified on 2026-11-02. The frequency-table component adapts the official Android android-7.1.1_r1 source. SDK structure layouts replace upstream declarations. The recovered implementation builds master, high-resolution, low-resolution, noise, and limiter bands. It includes sorting and the observed integer-logarithm, normalized multiplication, and logarithm helpers. Logarithm polynomial coefficients use the SDK's 16-bit configuration. Scratch arrays retain the observed zero initialization.
