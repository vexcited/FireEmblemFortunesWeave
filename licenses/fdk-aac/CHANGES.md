Third-Party Modified Version of the Fraunhofer FDK AAC Codec Library for Android.

Modified on 2026-11-02. The SBR envelope component adapts the official Android android-7.1.1_r1 envelope source and android-5.1.1_r1 arithmetic and lookup tables. SDK structure layouts replace upstream declarations. The recovered implementation retains fixed-point energy estimation, gain limiting, alias reduction, noise and harmonic assembly, and overlap scaling. The source includes the lookup tables required by these operations.
