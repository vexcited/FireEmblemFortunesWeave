This component is a Third-Party Modified Version of the Fraunhofer FDK AAC Codec
Library for Android.

Modified on 2026-11-03.

SBR header and element parsing, Huffman decoding, frame grids, harmonic flags,
and extension handling are adapted from the Android 7.1.1 release of the FDK
AAC library. The source uses the observed SDK namespace and object layouts.
The parser uses the recovered SDK bit reader and parametric stereo decoder.
Platform alternatives and unused eight-slot fixed-grid tables are omitted.
